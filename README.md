# Xnight CN 🇨🇳

### 面向中文 Web3 圈子的私密互动互助社群

**认真互动，互相支持，一起在中文 CT 圈里成长。**

Xnight CN 是一个面向中文 Web3 社区的邀请制 Telegram 私密社群，聚集活跃于中文 CT 的创作者、KOL、研究者和生态参与者。

我们希望把愿意认真做内容、积极参与社区互动、也愿意支持其他人的人连接起来。通过有节奏的互动和长期的社区协作，让成员更容易认识同行、建立关系，也为未来的创作者合作创造更多可能。

🔗 **官网：[xnightcn.vercel.app](https://xnightcn.vercel.app/)**

## 我们在做什么

### 🤝 互动互助

围绕成员在 X 上发布的 Web3 内容开展有组织的互动。比起单纯刷存在感，我们更希望大家能认真看内容、给出贴合主题的回应，让互动更自然，也更有价值。

### 🌐 连接中文 CT

把活跃于中文 Web3 圈子的创作者和参与者聚在一起，认识同行、交换想法，在持续互动中建立更稳定的联系。

### ⚖️ 公平参与

社区看重持续参与、互相尊重和规则意识。每位成员都应公平地支持他人，而不是只关注自己的帖子。

### 🚀 创作者合作机会

随着社区发展，Xnight CN 计划逐步探索 Web3 项目的 Creator/KOL 合作、付费活动及其他相关机会。具体机会取决于项目需求、资格要求和实际名额，并不保证每位成员都能获得。

## 互动方式

Xnight CN 通过 Telegram 组织互动，成员在 X 上分享自己的帖子，并按指定场次参与社区互动。

1. 查看官网或社群内公布的互动场次。
2. 在对应场次分享自己的 X 帖子直达链接。
3. 按照既定顺序参与互动，评论尽量结合原帖内容，用中文认真交流。
4. 完成该场次的互动后，按社群要求确认完成。

每天设有固定互动时段（中国标准时间 UTC+8）。具体安排和参与要求请以官网及社群公告为准。

## 适合哪些人加入？

Xnight CN 面向真正活跃于中文 Web3 社区、并愿意参与互助的用户。申请者需要符合以下基本要求：

- X 账号至少拥有 **1,000 名粉丝**。
- 拥有已认证的 X 账号。
- 持续参与中文 Web3 / CT 社区。
- 愿意认真参与互动，并遵守社群规则。

**Xnight CN 采用邀请制。** 满足基本条件并不代表自动获准加入，具体准入以社群审核及邀请安排为准。
